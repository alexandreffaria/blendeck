      - Fn still held after fine scrubbing redoes instead of undoing

    title: The same undo

      - Every button and knob keeps one action; Fn only changes how much
      - Can't redo by accident
    cons:
      - Redo stays on the keyboard; no button can do it until one is built

## Context

The undo button undoes once per press, with or without Fn. This sets the default profile;
the page can rebind Fn + any button to an existing action, but there is no redo action yet,
so picking redo means building one.
